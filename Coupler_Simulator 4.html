Equation reference — verified against QUCS MSTC source code
1Eeff — Hammerstad-Jensen 1980
u = W/h, g = S/h
a = 1 + ln((u^4+(u/52)^2)/(u^4+0.432))/49 + ln(1+(u/18.1)^3)/18.7
b = 0.564 * ((Er-0.9)/(Er+3))^0.053
Eeff = (Er+1)/2 + (Er-1)/2 * (1+10/u)^(-a*b)
2Z0 single — Wheeler 1977
if W/h < 1:
Z0 = (60/sqrt(Eeff)) * ln(8h/W + W/4h)
if W/h >= 1:
Z0 = 120*pi / [sqrt(Eeff)*(u+1.393 +0.667*ln(u+1.444))]
3Even/odd Eeff — Kirschning-Jansen 1984
Q1 = 0.8695 * u^0.194
Q2 = 1 + 0.7519g + 0.189g^2.31
Q3..Q10 = gap coupling factors of u, g
Eeff_e = Eeff0 + Q4*(Er-1)/(2*Q2)
Eeff_o = Eeff0 - Q10*(Er-1)/(2*Q2)
IEEE MTT-32(1), Jan 1984, pp.83-90
4Zoe / Zoo + coupling C
Zoe = Z0e_freespace / sqrt(Eeff_e)
Zoo = Z0o_freespace / sqrt(Eeff_o)
C = (Zoe - Zoo) / (Zoe + Zoo)
Z0S = sqrt(Zoe * Zoo) (port match Z)
Z0S should equal 50 ohm for port match
5S-parameters — Pozar Eq 7.63
Eeff_avg = (Eeff_e + Eeff_o) / 2
theta = pi * f * L * sqrt(Eeff_avg) / c
|S31| = |C*sin(t) / sqrt(1-C^2*cos^2(t))|
|S21| = |cos(t) / sqrt(1-C^2*cos^2(t))|
|S21|^2 + |S31|^2 = 1 (power conserved)
alpha(dB/in) = 2.3*f(GHz)*tand*sqrt(Eeff)
